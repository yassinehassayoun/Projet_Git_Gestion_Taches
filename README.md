
# Application Python de Gestion des Tâches

## Présentation
Ce projet est une application simple en Python permettant de gérer des tâches quotidiennes depuis une interface console.

## Fonctionnalités
- Ajouter une tâche avec un titre.
- Refuser les titres vides.
- Afficher toutes les tâches avec leur numéro.
- Rechercher une tâche à partir d'un mot-clé.
- Quitter le programme avec l'option 0.

## Étapes réalisées
- Création du programme Python dans le fichier main.py.
- Utilisation d'une liste pour stocker les tâches.
- Création de fonctions pour ajouter, afficher et rechercher les tâches.
- Création d'un menu avec une boucle while.
- Test du programme dans Visual Studio Code.

## Exécution du programme
1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier main.py.
3. Cliquer sur le bouton "Run Python File".
4. Utiliser le menu affiché dans la console.
